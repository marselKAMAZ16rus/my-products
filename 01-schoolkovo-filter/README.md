# Подсветка задач Школково

Расширение для браузера, которое подсвечивает нужные домашние задания в таблице проверки на платформе Школково. Помогает быстрее находить свои задания и не пропускать те, которые давно ожидают проверки.

## Как работает

- 🟡 **Жёлтый** — задание отправлено менее двух дней назад.
- 🔴 **Красный** — с даты отправки прошло два календарных дня или больше.
- Остальные задания не подсвечиваются.

Подсветка автоматически обновляется при изменении содержимого таблицы.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `script.js` и настройте список ID заданий (см. ниже).
4. Откройте страницу `chrome://extensions/` в Google Chrome.
5. Включите **Режим разработчика**.
6. Нажмите **Загрузить распакованное расширение**.
7. Выберите папку, содержащую `manifest.json` и `script.js`.
8. Откройте или обновите страницу с таблицей проверки на Школково.

## Настройка

### Список заданий

Откройте файл `script.js` и найдите массив `myHomeworkIds` в начале файла. Замените его содержимое на ID своих домашних заданий через запятую:

```javascript
const myHomeworkIds = [10001, 10002, 10003];
```

Числа приведены для примера.

### Срок проверки

По умолчанию задания подсвечиваются красным через два календарных дня с даты отправки. Чтобы изменить этот срок, найдите строку:

```javascript
const OLD_TASK_DAYS_THRESHOLD = 2;
```

Например, установите `3`, чтобы задания подсвечивались красным через три календарных дня.

После изменения настроек сохраните файл, нажмите кнопку обновления расширения на странице `chrome://extensions/` и перезагрузите страницу Школково.

## Если подсветка не работает

- Убедитесь, что расширение включено.
- Проверьте, правильно ли указаны ID заданий.
- Обновите расширение и перезагрузите страницу Школково.

При изменении структуры таблицы на сайте расширение может потребовать обновления.

## Конфиденциальность

Список ID хранится локально в файле `script.js`. Расширение не отправляет данные на сторонние серверы и не изменяет задания на платформе — только их визуальное отображение в браузере.
