# Помощник проверяющего (Windows)

Небольшая утилита для быстрого поиска комментариев из текстового банка.

## Горячая клавиша

**Ctrl + Shift + F8** показывает или скрывает окно поверх остальных окон.

- Поиск выполняется вручную: введи в строку, например, `ОДЗ`, `график`, `прогрессия`.
- Горячая клавиша не копирует выделение и не меняет содержимое буфера обмена.
- Нажми **Копировать** у нужного результата, затем вставь комментарий через **Ctrl + V**.
- **Esc**, кнопка «Скрыть» или крестик `X` прячет окно, но программа остаётся работать в фоне.
- Кнопка «Обновить банк» перечитывает файл комментариев без перезапуска программы.

## Установка

1. Установи Python 3.10 или новее с сайта https://www.python.org/downloads/.
2. При установке Python отметь **Add Python to PATH**.
3. Распакуй архив в отдельную папку.
4. Запусти `Установить.bat`.
5. После установки запусти `Запустить.bat`.

Чтобы завершить программу полностью, закрой её через Диспетчер задач. Для автоматического запуска вместе с Windows можно создать ярлык на `Запустить.bat` и поместить его в папку автозагрузки Windows (Win + R → `shell:startup`).

## Банк комментариев

Файл `банк_комментариев.txt` лежит рядом с программой.
Каждый комментарий отделяй от следующего **пустой строкой**. Можно редактировать файл в Блокноте.
После изменений нажми «Обновить банк» в программе.

## Важно

- Поиск сейчас локальный: содержимое банка не отправляется в интернет.
- Поиск основан на словах, сокращениях и текстовом сходстве. Это не полноценная нейросемантика: для сложных перефразировок качество может быть ограничено.
- Для глобальной горячей клавиши используется пакет `keyboard`. Если Windows не регистрирует сочетание, попробуй запустить программу от имени администратора.
- Горячая клавиша по умолчанию — `ctrl+shift+f8`; её можно поменять в переменной `HOTKEY` в начале `main.py`.
